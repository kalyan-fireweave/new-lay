## How to emit a metric — `apps/web` (web)

**This app's FireWeave files:** control points `apps/web/src/fireweave/control-points.ts`; start `apps/web/src/fireweave/start.ts`, imported first by `apps/web/src/main.tsx`; build config `apps/web/vite.config.ts`; stamps `.fireweave/stamps.ts`.

**Client:** `otel-sdk`

**Import, as it appears in this repo:** `n/a — apps/web/src/otel.ts builds OTLP export bodies by hand (no otel SDK import) and posts them to /otel, which apps/web/vite.config.ts proxies to the API's otelRoutes()`

**Counter:** `sendClick(label) in apps/web/src/otel.ts builds a single OTLP span per click (kind: 3, name: "click") and POSTs it as JSON to /otel; there are no counter/histogram calls in this app`

**Histogram / timing:** `none`

**Where the instrument comes from:** apps/web/src/otel.ts: a document-level capturing click listener on button/a/[role='button'], not an otel SDK meter/tracer instance

**Wrapper to prefer over the raw client:** sendClick(label) in apps/web/src/otel.ts

**Tag / label convention (including the cohort key):** OTLP span attributes: keel.signal="app", click.label=<element text>, plus keel.run_id/actor/journey/step/pace from window.__KEEL_RUN__ when present; resource attributes include service.name="keel-web"
